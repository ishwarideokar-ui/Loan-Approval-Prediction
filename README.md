# Customer Segmentation

## 📌 Project Overview
Customer Segmentation is a machine learning project that groups customers based on their characteristics and purchasing behavior using clustering techniques.

## 🎯 Objectives
- Identify different customer groups.
- Understand customer purchasing behavior.
- Help businesses improve marketing strategies.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- K-Means Clustering

## ⚙️ Project Workflow
1. Load the dataset.
2. Perform data cleaning and preprocessing.
3. Explore the data using EDA.
4. Scale the features.
5. Apply the K-Means clustering algorithm.
6. Visualize and analyze customer segments.

## 📊 Results
Customers are grouped into different clusters based on their similarities, helping businesses understand customer behavior and target the right audience.

## 📁 Project Structure
- `customer_segmentation.ipynb` – Project implementation
- `README.md` – Project documentation
- `dataset.csv` – Dataset used for analysis
